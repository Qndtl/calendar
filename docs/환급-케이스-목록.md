# 건강보험 및 국민연금 환급 케이스 목록

## 공통 시간 기준

캘린더에서 선택한 기준월(offset 0)을 기준으로 청구 시점까지의 거리로 표현합니다.

| 코드 offset | 시간 표기 |
|---|---|
| -2 | 5개월 전 |
| -1 | 4개월 전 |
| 0 (기준월) | 3개월 전 |
| +1 | 2개월 전 |
| +2 | 1개월 전 |

## 결과 유형

- **환급**: 3개월 전 공제된 금액 반환
- **환급 비대상**: 공제 유지 (환급 없음)
- **징수**: 미공제 금액 추가 징수
- **금액 비교**: 징수액 vs 환급액 비교 후 처리 (현재 미구현)

## 2. 국민연금 환급 (신규 로직)

**파일:** `src/logic/pension/new.js`  
**처리 기간:** 4개월 전 ~ 2개월 전  
**처리 단위:** 현장(companyId) 그룹별 독립 계산

**용어 정의:**
- `현장 임계치`: 현장 출역 ≥ 8일 **또는** 현장 임금 ≥ 220만원
- `청구업체 임계치`: 청구업체 전체 출역 ≥ 8일 **또는** 청구업체 전체 임금 ≥ 220만원
- `공제 정산(reconcile)`: 예상 공제일 vs 실제 공제일 비교 → 초과 공제분 환급 + 미공제분 징수

### shouldReconcile 판단 (우선순위 순)

| 우선순위 | 선행 조건 | shouldReconcile = true 조건 |
|---|---|---|
| 1 | 4개월 전 현장 출역 있음 **또는** 3개월 전 현장 초일+말일 동시 출역 | 현장 임계치 **또는** 청구업체 임계치 충족 |
| 2 | 4개월 전 청구업체 출역 있음 **또는** 3개월 전 청구업체 초일+말일 동시 출역 | 청구업체 임계치 충족 |
| 3 | 3개월 전 현장 초일 출역 + 말일 미출역 + 2개월 전 동일 현장 출역 있음 | 현장 임계치 충족 |
| 4 | 3개월 전 청구업체 초일 출역 + 2개월 전 청구업체 출역 있음 | 청구업체 출역 ≥ 8일 |

- `shouldReconcile = true` → **공제 정산**
- `shouldReconcile = false` → **환급** (현장 근무일 전체 환급, 공제 있으면)

## 3. 건강보험 환급 (기존 로직)

**파일:** `src/logic/health/existing.js`  
**처리 기간:** 5개월 전 ~ 1개월 전 (5개월 window)  
**처리 단위:** 건설사(companyId) 별 독립 계산  
**공통 전제:** 3개월 전 공제된 날짜가 있어야 환급 가능

> 아래 "+30일"은 고정 30일이 아닌, **첫 출역일이 속한 달의 일 수 − 1일**을 더한 날짜  
> ex) 3월 15일 첫 출역 → 3월은 31일 → +30일 = 4월 14일

### Case 1 — 4개월 전 출역 없음 + 3개월 전 초일(1일) 출역

| # | 3개월 전 출역 | 추가 조건 | 결과 |
|---|---|---|---|
| 1-1 | **< 8일** | — | 환급 |
| 1-2 | **≥ 8일** | 3개월 전 말일 출역 | 금액 비교 |
| 1-3 | **≥ 8일** | 말일 미출역 + 2개월 전 출역 **있음** | 금액 비교 |
| 1-4 | **≥ 8일** | 말일 미출역 + 2개월 전 출역 **없음** | 환급 |

### Case 2 — 4개월 전 출역 없음 + 3개월 전 초일 미출역 + 첫 출역 = 1/30 or 1/31

| # | 조건 | 결과 |
|---|---|---|
| 2-1 | [1/30(31) ~ 2월 말일] 출역 **< 8일** | 환급 |
| 2-2 | [1/30(31) ~ 2월 말일] 출역 **≥ 8일** + 2월 말일 출역 | 금액 비교 |
| 2-3 | [1/30(31) ~ 2월 말일] 출역 **≥ 8일** + 2월 말일 미출역 + 1개월 전 출역 **있음** | 금액 비교 |
| 2-4 | [1/30(31) ~ 2월 말일] 출역 **≥ 8일** + 2월 말일 미출역 + 1개월 전 출역 **없음** | 환급 |

### Case 3 — 4개월 전 출역 없음 + 3개월 전 초일 미출역 + 첫 출역 일반 날짜

| # | 3개월 전 출역 | 기간/조건 | 결과 |
|---|---|---|---|
| 3-1 | **≥ 8일** | 첫 출역+30일에 출역 **있음** | 금액 비교 |
| 3-2 | **≥ 8일** | 첫 출역+30일 미출역 + [+31일~2개월 전 말일] 출역 **있음** | 금액 비교 |
| 3-3 | **≥ 8일** | 첫 출역+30일 미출역 + [+31일~2개월 전 말일] 출역 **없음** | 환급 |
| 3-4 | **< 8일** | [첫 출역~+30일] **≥ 8일** + 첫 출역+30일 출역 **있음** | 금액 비교 |
| 3-5 | **< 8일** | [첫 출역~+30일] **≥ 8일** + 첫 출역+30일 없음 + [+31일~] **있음** | 금액 비교 |
| 3-6 | **< 8일** | [첫 출역~+30일] **≥ 8일** + 첫 출역+30일 없음 + [+31일~] **없음** | 환급 |
| 3-7 | **< 8일** | [첫 출역~+30일] **< 8일** | 환급 |

### Case 4 — 4개월 전 출역 있음 + 5개월 전 출역 있음

| # | 3개월 전 출역 | 결과 |
|---|---|---|
| 4-A | **≥ 8일** | 금액 비교 |
| 4-B | **< 8일** | 환급 |

### Case 5 — 4개월 전 출역 있음 + 5개월 전 없음 + 4개월 전 초일 출역

## 4. 건강보험 환급 (신규 로직 v2)

**파일:** `src/logic/health/new.js` (`calculateHealthInsuranceRefund`)  
**처리 기간:** 5개월 전 ~ 2개월 전 (4개월 window)  
**처리 단위:** 건설사(companyId) 별 독립 계산

**기간 정의:**
- `totalDays` = 4개월 전 없으면 (3개월 전 + 2개월 전), 있으면 (4개월 전 + 3개월 전)
- `period4Count` = [4개월 전 첫 출역 ~ 첫 출역+30일] 범위 내 출역 수
- `period3Count` = [3개월 전 첫 출역 ~ 첫 출역+30일] 범위 내 출역 수

### Step 1 — 합산 출역 < 8일

| # | 조건 | 결과 |
|---|---|---|
| S1 | `totalDays < 8` | 환급 (공제 있으면) |

### Step 3-4 — 두 기간 모두 < 8일

| # | 조건 | 결과 |
|---|---|---|
| S3 | `period4Count < 8` AND `period3Count < 8` | 환급 (공제 있으면) |

### Step 5a — 4개월 전 있음 + period4Count ≥ 8

**공제 정당 조건** (하나라도 충족하면 정당):
1. `period4End` (첫 출역+30일) 이후 출역 있음
2. 4개월 전 첫 출역 = 1/30 or 1/31 AND 3개월 전 말일 출역
3. 5개월 전 출역 있음

| # | 조건 | 결과 |
|---|---|---|
| 5a-A | 공제 정당 조건 **미충족** | 환급 (공제 부당) |
| 5a-B | 공제 정당 + 5개월 전 있음 + 3개월 전 **< 8일** | 환급 비대상 |
| 5a-C | 공제 정당 + 공제 내역 **없음** | 징수 |
| 5a-D | 공제 정당 + 공제 내역 **있음** | 금액 비교 |

### Step 5b — 4개월 전 있음 + period4Count < 8 (period3Count ≥ 8 보장)

| # | 조건 | 결과 |
|---|---|---|
| 5b-A | 3개월 전 출역 **< 8일** | 환급 (공제 있으면) |
| 5b-B | 3개월 전 출역 **≥ 8일** + 공제 내역 **없음** | 징수 |
| 5b-C | 3개월 전 출역 **≥ 8일** + 공제 내역 **있음** | 금액 비교 |

### Step 5c — 4개월 전 없음 + period3Count ≥ 8

**면제 조건 A:** 3개월 전 초일 출역 AND (3개월 전 말일 출역 **또는** 2개월 전 출역 있음)

| # | 조건 | 결과 |
|---|---|---|
| 5c-A | 면제 조건 **미충족** | 환급 (공제 부당) |
| 5c-B | 면제 조건 충족 + 공제 내역 **없음** + 3개월 전 **≥ 8일** | 징수 |
| 5c-C | 면제 조건 충족 + 공제 내역 **있음** | 금액 비교 |
